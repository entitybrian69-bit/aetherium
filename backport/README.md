# Aetherium Backport (Minecraft 1.12.2, Forge)

The Aetherium client mod for Minecraft 1.12.2 on Forge. Requires [MixinBooter](https://modrinth.com/mod/mixinbooter).

- Shares the platform-neutral code in `../common` (the list is `ci/shared-sources.txt`, generated by `ci/shared_closure.py`).
- 1.12.2-specific code: `src/main/java/com/aetherium/{backport,client,mixin}`; hooks are MCP-named mixins in `mixin/core`.
- Built with RetroFuturaGradle (`./gradlew build`, Java 8 toolchain).
- CI (`.github/workflows/backport.yml`): build, javap probe of the 1.12.2 classes, then an in-game smoke test under Xvfb
  (menu, new world, renderer vs vanilla screenshots, every settings tab). Results land in `ci/out`.
- A commit containing `[backport-release]` publishes the GitHub release `backport-v<version>+1.12.2` and the Modrinth
  version, only when the build and the smoke test pass.
